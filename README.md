# prestaedit.github.io

Blog technique de Jonathan Danse ([prestaedit.com](https://prestaedit.com)) — *PrestaShop, sous le capot.*

Publié sur **[blog.prestaedit.com](https://blog.prestaedit.com)** via Cloudflare Pages.

## Structure

Le site vit dans [`poc-astro/`](./poc-astro) (Astro 5 + Tailwind v4 + Preline + Keystatic).
Voir [`poc-astro/README.md`](./poc-astro/README.md) pour le dev, le build et le déploiement.

## Historique

Ce repo a précédemment servi un blog VuePress publié sur `prestaedit.github.io` via GitHub Pages
(theme mediumish). La refonte Astro a eu lieu en juillet 2026. La branche `gh-pages` sert
désormais uniquement une page de redirection vers le nouveau domaine.
